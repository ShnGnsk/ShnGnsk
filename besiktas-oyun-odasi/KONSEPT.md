# Beşiktaş Temalı Oyun Odası — Konsept & Alışveriş Rehberi

Küçük dikdörtgen çalışma odanı **Kartal Yuvası** ruhunda, siyah–beyaz–antrasit paletli bir oyun + seyir odasına dönüştüren plan.

Dağınıklık dikkate alınmadı; mevcut pembe kanepe, eski masa, açık raflar ve depolama kaldırıldığı varsayıldı. Mevcut Vestel TV duvara asılı kalabilir.

---

## 1. Oda düzeni (önerilen yerleşim)

```
        [KAPI]
           |
  +--------+------------------+
  | TV duvarı (antrasit)      |
  |   [TV] + soundbar         |
  |   forma + LED kartal      |
  |                           |
  |   === HALI ===            |
  |   [3'lü KOLTUK]           |
  |                           |
  | [OYUNCU MASASI + 2 MON]---|  ← pencere duvarı
  | [sandalye] [kasa] [ses]   |
  +---------------------------+
```

| Bölge | Ne olur |
|--------|---------|
| **TV duvarı** | Antrasit vurgu boyası, duvar TV, soundbar, Beşiktaş forma çerçevesi + LED logo |
| **Karşı duvar** | 3 kişilik kompakt kanepe (≈170 cm) |
| **Pencere yanı** | 160 cm oyuncu masası, çift monitör, kasa, ses sistemi, oyuncu sandalyesi |
| **Orta** | Siyah-beyaz Beşiktaş motifli halı |
| **Pencere** | Siyah zebra + siyah fon perde |

Küçük odada L-kanepe **önerme** — GLOSTAD gibi 171 cm düz 3’lü sığar, yürüyüş yolu kalır.

## 7. Stil kuralları (Kartal Yuvası, dağınık taraftar odası değil)

- Ana palet: **siyah · beyaz · antrasit · açık gri**  
- RGB: sadece **beyaz / soğuk beyaz** (gökkuşağı LED yok)  
- Pembe/turuncu tekstil yok  
- Kartal logosu 2–3 noktada (halı + LED + bir çerçeve) — her yüzeyi basma  
- Açık rafları kaldır; depolama kapalı dolap veya başka odaya
