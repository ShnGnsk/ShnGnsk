# 1903 Atölye — Beşiktaş Oda Tasarımı

Salon kapısı, balkon kapısı, karşı cam + petek ve 40 cm kiriş / 20 cm girintiye göre Beşiktaş (siyah-beyaz) konseptli oda düzeni. Mobilyalar internette satılan gerçek ürünlerle eşleştirildi.

## Görüntüle

```bash
cd oda-tasarim
python3 -m http.server 4173
```

Tarayıcı: [http://localhost:4173](http://localhost:4173)
