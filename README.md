# ShnGnsk — Atölye Oda Tasarımı

Fotoğraflardan çıkarılan mimari analiz ve yeniden düzen önerisi.

## Görüntüle

```bash
cd oda-tasarim
python3 -m http.server 4173
```

Tarayıcıda: [http://localhost:4173](http://localhost:4173)

## İçerik

- Kapı, pencere, duvar girintileri analizi
- Mevcut / önerilen kat planı
- Üç bölgeli düzen (depo · çalışma · oturma)
- Malzeme paleti ve uygulama sırası
- Görsel mockuplar (`oda-tasarim/assets/`)
